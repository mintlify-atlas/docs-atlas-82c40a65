Welcome to Unit 1, where **you'll build a solid foundation in the fundamentals of AI agents** including:

<CardGroup cols={2}>
  <Card title="Understanding agents" icon="robot">
    What is an agent, and how does it work? How do agents make decisions using reasoning and planning?
  </Card>
  <Card title="The role of LLMs" icon="brain">
    How LLMs serve as the "brain" behind an agent. How LLMs structure conversations via the messages system.
  </Card>
  <Card title="Tools and actions" icon="wrench">
    How agents use external tools to interact with the environment. How to build and integrate tools for your agent.
  </Card>
  <Card title="The agent workflow" icon="arrow-right-arrow-left">
    The core Think → Act → Observe cycle that drives every agent.
  </Card>
</CardGroup>

After exploring these topics, **you'll build your first agent** using `smolagents`!

Your agent, named Alfred, will handle a simple task and demonstrate how to apply these concepts in practice. You'll even learn how to **publish your agent on Hugging Face Spaces**, so you can share it with friends and colleagues.

At the end of this unit, you'll take a quiz. Pass it, and you'll **earn your first course certification**: the Certificate of Fundamentals of Agents.

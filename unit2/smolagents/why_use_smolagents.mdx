In this module, you'll explore the pros and cons of using [smolagents](https://huggingface.co/docs/smolagents/en/index), helping you make an informed decision about whether it's the right framework for your needs.

## What is `smolagents`?

`smolagents` is a simple yet powerful framework for building AI agents. It provides LLMs with the _agency_ to interact with the real world — for example, searching the web or generating images.

As covered in Unit 1, AI agents are programs that use LLMs to generate **thoughts** based on **observations** to perform **actions**. Here's how this is implemented in `smolagents`.

### Key advantages

- **Simplicity:** Minimal code complexity and abstractions make the framework easy to understand, adopt, and extend.
- **Flexible LLM support:** Works with any LLM through integration with Hugging Face tools and external APIs.
- **Code-first approach:** First-class support for code agents that write their actions directly in code, removing the need for parsing and simplifying tool calling.
- **HF Hub integration:** Seamless integration with the Hugging Face Hub, allowing the use of Gradio Spaces as tools.

### When to use `smolagents`

`smolagents` is ideal when:

- You need a **lightweight and minimal solution**.
- You want to **experiment quickly** without complex configurations.
- Your **application logic is straightforward**.

## Code vs. JSON actions

Unlike other frameworks where agents write actions in JSON, `smolagents` **focuses on tool calls in code**, simplifying the execution process. There's no need to parse JSON in order to build code that calls the tools — the output can be executed directly.

![Code vs. JSON actions](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)

To review the difference between code and JSON actions, revisit the [Actions section in Unit 1](https://huggingface.co/learn/agents-course/unit1/actions#actions-enabling-the-agent-to-engage-with-its-environment).

## Agent types in `smolagents`

Agents in `smolagents` operate as **multi-step agents**.

Each [`MultiStepAgent`](https://huggingface.co/docs/smolagents/main/en/reference/agents#smolagents.MultiStepAgent) performs:

- One thought
- One tool call and execution

In addition to using **[CodeAgent](https://huggingface.co/docs/smolagents/main/en/reference/agents#smolagents.CodeAgent)** as the primary agent type, `smolagents` also supports **[ToolCallingAgent](https://huggingface.co/docs/smolagents/main/en/reference/agents#smolagents.ToolCallingAgent)**, which writes tool calls in JSON.

<Tip>
  In `smolagents`, tools are defined using the `@tool` decorator wrapping a Python function, or the `Tool` class.
</Tip>

## Model integration

`smolagents` supports flexible LLM integration, allowing you to use any callable model that meets [certain criteria](https://huggingface.co/docs/smolagents/main/en/reference/models). The framework provides several predefined classes to simplify model connections:

<AccordionGroup>
  <Accordion title="TransformersModel">
    Implements a local `transformers` pipeline for seamless integration. See [docs](https://huggingface.co/docs/smolagents/main/en/reference/models#smolagents.TransformersModel).
  </Accordion>
  <Accordion title="InferenceClientModel">
    Supports [serverless inference](https://huggingface.co/docs/huggingface_hub/main/en/guides/inference) calls through Hugging Face's infrastructure, or via a growing number of [third-party inference providers](https://huggingface.co/docs/huggingface_hub/main/en/guides/inference#supported-providers-and-tasks). See [docs](https://huggingface.co/docs/smolagents/main/en/reference/models#smolagents.InferenceClientModel).
  </Accordion>
  <Accordion title="LiteLLMModel">
    Leverages [LiteLLM](https://www.litellm.ai/) for lightweight model interactions. See [docs](https://huggingface.co/docs/smolagents/main/en/reference/models#smolagents.LiteLLMModel).
  </Accordion>
  <Accordion title="OpenAIServerModel">
    Connects to any service that offers an OpenAI API interface. See [docs](https://huggingface.co/docs/smolagents/main/en/reference/models#smolagents.OpenAIServerModel).
  </Accordion>
  <Accordion title="AzureOpenAIServerModel">
    Supports integration with any Azure OpenAI deployment. See [docs](https://huggingface.co/docs/smolagents/main/en/reference/models#smolagents.AzureOpenAIServerModel).
  </Accordion>
</AccordionGroup>

This flexibility ensures you can choose the model and service most suitable for your specific use case, and allows for easy experimentation.

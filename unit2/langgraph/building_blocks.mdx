## 1. State

**State** is the central concept in LangGraph. It represents all the information that flows through your application.

```python
from typing_extensions import TypedDict

class State(TypedDict):
    graph_state: str
```

The state is **user-defined**, so its fields should be carefully crafted to contain all the data needed for the decision-making process.

<Tip>
  Think carefully about what information your application needs to track between steps. A well-designed state is the foundation of a maintainable graph.
</Tip>

## 2. Nodes

**Nodes** are Python functions. Each node:

- Takes the state as input
- Performs some operation
- Returns updates to the state

```python
def node_1(state):
    print("---Node 1---")
    return {"graph_state": state['graph_state'] +" I am"}

def node_2(state):
    print("---Node 2---")
    return {"graph_state": state['graph_state'] +" happy!"}

def node_3(state):
    print("---Node 3---")
    return {"graph_state": state['graph_state'] +" sad!"}
```

Nodes can contain any of the following:

<CardGroup cols={2}>
  <Card title="LLM calls" icon="brain">
    Generate text or make decisions using a language model.
  </Card>
  <Card title="Tool calls" icon="wrench">
    Interact with external systems, APIs, or databases.
  </Card>
  <Card title="Conditional logic" icon="code-branch">
    Determine which step comes next based on the current state.
  </Card>
  <Card title="Human intervention" icon="user">
    Pause execution to collect input from a user before proceeding.
  </Card>

<Info>
  Some nodes necessary for the whole workflow — like `START` and `END` — are provided directly by LangGraph.
</Info>

## 3. Edges

**Edges** connect nodes and define the possible paths through your graph.

```python
import random
from typing import Literal

def decide_mood(state) -> Literal["node_2", "node_3"]:
    
    # Often, we will use state to decide on the next node to visit
    user_input = state['graph_state'] 
    
    # Here, let's just do a 50 / 50 split between nodes 2, 3
    if random.random() < 0.5:

        # 50% of the time, we return Node 2
        return "node_2"
    
    # 50% of the time, we return Node 3
    return "node_3"
```

Edges come in two forms:

- **Direct**: Always go from node A to node B.
- **Conditional**: Choose the next node based on the current state.

## 4. StateGraph

The **StateGraph** is the container that holds your entire agent workflow. You add nodes, define edges, and then compile the graph:

```python
from IPython.display import Image, display
from langgraph.graph import StateGraph, START, END

# Build graph
builder = StateGraph(State)
builder.add_node("node_1", node_1)
builder.add_node("node_2", node_2)
builder.add_node("node_3", node_3)

# Logic
builder.add_edge(START, "node_1")
builder.add_conditional_edges("node_1", decide_mood)
builder.add_edge("node_2", END)
builder.add_edge("node_3", END)

# Add
graph = builder.compile()
```

Once compiled, you can visualize the graph:

```python
# View
display(Image(graph.get_graph().draw_mermaid_png()))
```

Welcome to this next part of your journey, where you'll learn **how to build applications** using [LangGraph](https://github.com/langchain-ai/langgraph) — a framework designed to help you structure and orchestrate complex LLM workflows.

`LangGraph` is a framework that allows you to build **production-ready** applications by giving you **control** over the flow of your agent.

<Warning>
  The examples in this section require access to a powerful LLM/VLM model. The examples were run using the GPT-4o API because it has the best compatibility with LangGraph.
</Warning>

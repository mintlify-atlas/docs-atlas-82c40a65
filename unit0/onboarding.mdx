## Running models locally with Ollama

If you hit API credit limits during the course, you can run models locally using [Ollama](https://ollama.com/download) as a drop-in replacement.

<Steps>
  <Step title="Install Ollama">
    Follow the official installation instructions at [ollama.com/download](https://ollama.com/download).
  </Step>

  <Step title="Pull a model locally">
    ```bash
    ollama pull qwen2:7b
    ```

    This pulls the [qwen2:7b model](https://ollama.com/library/qwen2:7b). Browse [ollama.com/search](https://ollama.com/search) for additional models.
  </Step>

  <Step title="Start Ollama in the background">
    In a dedicated terminal, run:

    ```bash
    ollama serve
    ```

    <Note>
      If you see the error `listen tcp 127.0.0.1:11434: bind: address already in use`, run `sudo lsof -i :11434` to find the process using that port. If it's already `ollama`, the installation script started the service automatically and you can skip this step.
    </Note>
  </Step>

  <Step title="Switch to LiteLLMModel in smolagents">
    Install the `litellm` extra for smolagents:

    ```bash
    pip install 'smolagents[litellm]'
    ```

    Then replace `InferenceClientModel` with `LiteLLMModel` in your code:

    ```python
    from smolagents import LiteLLMModel

    model = LiteLLMModel(
        model_id="ollama_chat/qwen2:7b",  # or another Ollama-supported model
        api_base="http://127.0.0.1:11434",  # default Ollama local server
        num_ctx=8192,
    )
    ```

    Ollama serves models using an OpenAI-compatible API, so `LiteLLMModel` connects to it seamlessly — no other code changes required.
  </Step>
</Steps>

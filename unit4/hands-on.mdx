Now that you are ready to build your final agent, this page explains how the evaluation dataset works, how to interact with the scoring API, and how to submit your results.

## The dataset

The evaluation dataset consists of **20 questions** extracted from the Level 1 questions of the **validation** set from GAIA. The questions were filtered based on the number of tools and steps needed to answer them.

<Info>
  Based on the current state of the GAIA benchmark, a score of **30% on Level 1 questions** is considered a fair and meaningful target for this course.
</Info>

![GAIA leaderboard current status](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit4/leaderboard%20GAIA%2024%3A04%3A2025.png)

## The scoring API

For this unit, a dedicated API lets you retrieve questions and submit your agent's answers for scoring. The full interactive documentation is available at the [live API docs](https://agents-course-unit4-scoring.hf.space/docs).

| Route | Method | Description |
|---|---|---|
| `/questions` | `GET` | Retrieve the full list of filtered evaluation questions. |
| `/random-question` | `GET` | Fetch a single random question from the list. |
| `/files/{task_id}` | `GET` | Download a specific file associated with a given task ID. |
| `/submit` | `POST` | Submit agent answers, calculate the score, and update the leaderboard. |

<Warning>
  The `/submit` endpoint compares answers using **exact match**. Make sure your agent's final answer is concise and precisely formatted. Do **not** include the text "FINAL ANSWER" in your submission — your agent should reply with only the answer itself.
</Warning>

The GAIA team provides a prompting example on the [leaderboard page](https://huggingface.co/spaces/gaia-benchmark/leaderboard) that you can adapt for your agent.

## Getting started with the template

<Steps>
  <Step title="Duplicate the template space">
    Start from the [official template](https://huggingface.co/spaces/agents-course/Final_Assignment_Template) by duplicating it to your own Hugging Face profile.
  </Step>
  <Step title="Customize your agent">
    Modify the template however you like — change the agent framework, add tools, restructure the code. You are actively encouraged to make it your own rather than submitting the template unchanged.
  </Step>
  <Step title="Keep your space public">
    The leaderboard displays a link to your space's codebase. Keep your space public so your submission can be verified.
  </Step>
  <Step title="Prepare your submission payload">
    Your submission to the `/submit` endpoint requires three pieces of information:

    - **`username`** — your Hugging Face username (obtained via Gradio login), used to identify your submission.
    - **`agent_code`** — the URL to your Hugging Face Space code (`…/tree/main`) for verification.
    - **`answers`** — a list of responses in the format `{"task_id": ..., "submitted_answer": ...}` generated by your agent.
  </Step>
  <Step title="Submit and check your score">
    Call the `/submit` endpoint with your payload. Your score will be calculated and your result posted to the student leaderboard.
  </Step>
</Steps>
